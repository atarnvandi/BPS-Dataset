# 📊 BPS Data Pipeline - Sulawesi Selatan

Repository ini menyimpan data statistik resmi dari BPS (Badan Pusat Statistik) untuk 24 Kabupaten/Kota di Provinsi Sulawesi Selatan. Data diambil secara otomatis setiap bulan (Git Scraping).

## 🗂️ Variabel Data yang Diambil
- **TPT (Tingkat Pengangguran Terbuka)**
- **PDRB (Produk Domestik Regional Bruto) Harga Berlaku**
- **Inflasi Bulanan (M-to-M)**
- **Garis Kemiskinan**
